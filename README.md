# bread-king-bad
🍞 AI Bread Moldy Detector adalah website sederhana berbasis AI untuk mendeteksi apakah roti masih fresh atau sudah berjamur melalui gambar. User cukup mengunggah foto roti lalu sistem akan menganalisis dan menampilkan hasil deteksi secara otomatis. Dibuat menggunakan HTML, CSS, dan JavaScript dengan tampilan responsive dan mudah digunakan.
