🍞 AI Bread Moldy Detector

AI Bread Moldy Detector adalah project website berbasis Artificial Intelligence yang digunakan untuk mendeteksi apakah roti masih layak dikonsumsi atau sudah berjamur (moldy) melalui gambar/foto. Sistem ini dirancang dengan tampilan sederhana dan mudah digunakan sehingga user hanya perlu mengunggah gambar roti untuk mendapatkan hasil deteksi secara otomatis.

Project ini memanfaatkan teknologi AI image detection untuk mengenali ciri-ciri jamur pada permukaan roti dengan proses yang cepat dan efisien. Selain itu, website dibuat responsive agar dapat digunakan di berbagai perangkat seperti laptop maupun smartphone.

✨ Features
🔍 Deteksi roti berjamur menggunakan AI
📷 Upload gambar roti secara langsung
⚡ Prediksi cepat dan otomatis
🖥️ Tampilan website sederhana dan responsive
🌐 Dapat dijalankan langsung di browser
🛠️ Technologies Used
HTML
CSS
JavaScript
📂 How It Works
User mengunggah gambar roti
Sistem memproses gambar yang diinput
AI menganalisis kondisi roti
Hasil deteksi akan ditampilkan:
Fresh Bread ✅
Moldy Bread ❌
🎯 Purpose

Project ini dibuat untuk membantu mendeteksi kualitas roti secara otomatis dan mengurangi risiko konsumsi makanan yang sudah tidak layak.
